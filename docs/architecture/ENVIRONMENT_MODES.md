# Local, cloud-independent, and hybrid environment contracts

## Evidence rule

Environment routes have independent requirements and receipts. A green local route does not prove cloud availability; a cloud contract does not prove a local device/session. `ABSENT`, `FAIL`, `NOT_IMPLEMENTED`, and `NOT_EXERCISED` remain distinct.

## Mode L — pure local

### Required inputs

- exact Agent Shield commit/release;
- local Bun/TypeScript toolchain for admitted services and Harness work;
- selected local provider profile;
- host-brokered credentials only when the selected task explicitly needs them.

### Flow

```text
local request
  → local ingress/CLI
  → fresh local disposable runtime
  → typed module boundary
  → local artifacts and cleanup receipt
```

### Non-goals

- no cloud credential requirement for a local-only task;
- no claim that Apple Container, simulator, browser, tmux, or hardware exists until its canary runs;
- no committed `.env` or host path.

## Mode C — cloud-independent

### Required inputs

- immutable release or selected module bundle;
- closed typed request/bundle;
- cloud provider profile and limits;
- brokered secret references, never secret values in the payload;
- external artifact target.

### Flow

```text
webhook/schedule/Agent request
  → authenticated bounded gateway
  → fresh cloud runtime
  → exact selected closure
  → artifacts/receipt
  → runtime, process and lease cleanup
```

### Independence assertion

The cloud path cannot read the owner's live checkout, local Keychain, browser profile, device session, localhost service, or mutable `main`. An unavailable provider is reported by name.

## Mode H — hybrid update/repair

Hybrid mode is an exchange between independent environments, not one shared writable filesystem.

### Data-class routing

| Data class | Admitted mechanism | Conflict/recovery rule |
|---|---|---|
| source code | Git branch/commit/patch with single-writer lease | content/base identity + review + rebase; never timestamps |
| generated artifacts | content-addressed object/artifact store | immutable digest, regenerate or select exact version |
| policy/config | versioned schema and policy epoch | validate, stage, promote, rollback by exact version |
| OS/dependencies | image/template build | rebuild and pin; filesystem sync is insufficient |
| database/memory | API/event/log/snapshot protocol | provider-specific consistency and restore controls |
| secrets | host/cloud broker | no file synchronization |
| browser/device sessions | session broker owned by execution plane | never copied between local and cloud |

### Source update flow

```text
Worker obtains branch/path lease
  → records base commit/tree
  → edits in one environment
  → produces commits or content-bound patch
  → verifies path ownership and base
  → Git Town stack sync/rebase
  → reruns evals
  → safe push and PR
```

### Failure handling

- divergent source base: `FAIL`, no auto-override;
- missing provider/profile: `ABSENT` or `NOT_IMPLEMENTED`;
- provider present but not run: `NOT_EXERCISED`;
- semantic rebase conflict: suspended state and recovery assignment;
- leaked process/worktree/artifact/lock: cleanup failure independent from task result.

## Repair categories

### Source repair

Git ancestry, reviewable patches, and exact base digests. The source document's `newest`/`prefer-beta` proposal is recorded but rejected for source authority.

### Artifact repair

Re-materialize from immutable source, generator version, inputs, and digest. Do not edit generated bytes in place.

### Data repair

Restore from provider-owned append log/snapshot and verify domain invariants. A Merkle root or backup proves only its named property; it is not automatic full-state reconstruction.

### Key/access repair

Dedicated provider ceremony, revocation, rotation or resharing with audit and Human Admit. Documentation does not prove cryptographic recovery.

### Runtime/session repair

Reconnect only when the provider's lifecycle contract preserves an exact session. tmux is a source-proposed candidate for terminal persistence, not a universal durability guarantee.
