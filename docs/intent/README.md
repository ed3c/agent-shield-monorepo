# Project intent

This directory records what the project is trying to achieve and what the current phase is allowed to change.

## Rules

- Intent is not implementation evidence.
- Long-term product goals and current delivery scope must be separate.
- Every repository decision must map to an intent ID in the traceability index.
- A deferred goal remains visible with a reason and required evidence.
- Changes to project intent require an issue, evals, and an explicit decision record.

Canonical document: [`PROJECT_INTENT.md`](PROJECT_INTENT.md).
