# Immutable module releases

This directory contains deterministic portable release manifests generated by `scripts/release-manifest.ts`.

## Current release

`agent-shield-module-set.json` binds:

- release and runtime identity;
- each module ID and interface version;
- canonical module-manifest digest;
- owned roots, provided/required capabilities, runtime declaration, and external exposure;
- selected shared contract/document digests;
- a self-verifying `content_sha256`.

## Rules

- Regenerate after any bound module manifest or contract/context byte changes.
- CI writes the expected manifest to a temporary path and byte-compares parsed JSON.
- Do not hand-edit digests or claim a stale release is current.
- The release binds portable bytes only. Git commit/tree, origin reachability, bettor initialization, providers, subscriptions, browsers, devices, hardware, and settlement need separate receipts.
- `live_state: NOT_EXERCISED` is intentional until the exact release receives live evidence.
- Promotion and rollback must name exact commit, tree, release manifest, and Human Admit.

A consumer may pin this manifest but may not treat it as a runtime or security certification.
